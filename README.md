# WorkVision AI — منصة تحليل السلامة المهنية

منصة ويب عربية RTL لتحليل الصور والفيديو باستخدام نماذج YOLO الثلاثة المرفقة.

## المزايا
- رفع صورة أو فيديو وتحليله.
- تشغيل نموذج المخاطر أو PPE أو الأشخاص، أو تشغيل النماذج الثلاثة معًا.
- عرض الصورة/الفيديو بعد وضع مربعات الاكتشاف.
- مؤشرات: إجمالي الاكتشافات، الأشخاص، المخاطر، معدات الوقاية.
- جدول تفصيلي بالفئة والثقة والوقت/الإطار وموقع الصندوق.
- تنزيل تقرير PDF وملف CSV ونتائج JSON.
- واجهة متجاوبة مع الهاتف والكمبيوتر.

## التشغيل على Windows

1. ثبّت Python 3.10 أو 3.11 أو 3.12.
2. افتح PowerShell داخل مجلد المشروع.
3. أنشئ بيئة افتراضية:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

4. شغّل الخادم:

```powershell
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

5. افتح المتصفح على:
`http://127.0.0.1:8000`

للوصول من هاتف على نفس شبكة Wi-Fi، افتح `http://IP-OF-PC:8000` بعد السماح بالمنفذ 8000 في جدار الحماية.

## ملاحظات مهمة
- أول تشغيل قد يستغرق وقتًا لتحميل النماذج إلى الذاكرة.
- افتراضيًا يعمل النظام على CPU. إذا كان لديك CUDA متوافق، غيّر `DEVICE` إلى `0`.
- أسماء الفئات تُقرأ مباشرة من ملفات النماذج وقت التشغيل؛ لا يتم افتراض أسماء فئات غير موجودة داخل النموذج.
- الفيديو يُحلّل بأخذ عينة إطارات وفق `VIDEO_INTERVAL` لتقليل زمن المعالجة. غيّر القيمة في `app.py` أو متغير البيئة.
- نتائج النموذج مساعدة لاتخاذ القرار وليست بديلًا عن مراجعة مسؤول السلامة.
- لا ترفع فيديوهات تحتوي على بيانات شخصية إلا وفق سياسة الخصوصية المعتمدة لديك.

## هيكل المشروع
- `app.py`: واجهة API وتحميل النماذج والتحليل والتقارير.
- `static/`: واجهة المستخدم.
- `models/`: ملفات النماذج المدربة.
- `outputs/`: ملفات النتائج التي يتم إنشاؤها تلقائيًا.
